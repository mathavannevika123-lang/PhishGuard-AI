# PhishGuard AI 🛡️
### AI-Powered Digital Scam & Phishing Protection
**HacXLerate 2026 • Team Elite Squad**

---

## 📌 Executive Summary
PhishGuard AI is an **explainable, multi-channel cybersecurity defense platform** engineered to detect, demystify, and counteract modern digital scams and phishing attacks before damage occurs.

Unlike traditional blocklist-based scanners that fail against newly registered burner domains and nuanced psychological manipulation, PhishGuard AI leverages a **hybrid architecture** combining **Machine Learning (Random Forest & NLP Logistic Regression)** with an **interpretable heuristic rule engine** to analyze URLs, SMS/chat messages, and spoofed emails.

---

## 🚀 Key Features

### 1. 🌐 Multi-Channel Threat Scanner
- **URL Phishing Scanner**: Dissects domain entropy, suspicious TLDs (`.xyz`, `.top`, `.buzz`, `.cfd`), typosquatting/homoglyphs (`paypa1`, `arnazon`), deceptive subdomain chains, and raw IP addresses.
- **Scam Message Analyzer (SMS / WhatsApp / Telegram)**: Evaluates high-pressure urgency cues, legal intimidation/extortion threats, fake lottery/crypto rewards, and sensitive credential solicitation (KYC, PAN, OTP).
- **Email Risk Analyzer**: Detects display name spoofing (`PayPal Support <billing@fake-domain.xyz>`), subject line aggression, and malicious embedded links.

### 2. 🧠 Explainable AI (XAI) Engine
- Produces a transparent **0–100 Unified Risk Score** categorized into:
  - 🟢 **SAFE (0–29)**
  - 🟡 **SUSPICIOUS (30–69)**
  - 🔴 **DANGEROUS (70–100)**
- Clear, plain-English breakdown of *why* an alert was triggered, translating technical signals for students, families, and seniors.
- Threat vector radar breakdown: *Domain Trust*, *Brand Integrity*, *Urgency Intensity*, *Credential Theft Risk*.
- **Actionable User Playbook**: Exact next steps (*Avoid, Block, Report, Verify via official channel*).

### 3. 🎯 1-Click Judge Presets
Instant demo buttons covering all three risk tiers:
- **Safe**: Legitimate Google Drive sharing links, official Amazon delivery updates, and campus reminders.
- **Suspicious**: Burner-domain contest giveaways and unverified Telegram part-time job solicitations.
- **Dangerous**: Typosquatted PayPal credential harvesters, urgent bank account freeze SMS with fake KYC links, and spoofed Netflix suspension emails.

### 4. 📊 Threat Intelligence & Security Dashboard
- Real-time telemetry metrics: Total Scans, Dangerous Blocked, Suspicious Flagged, Threat Detection Rate.
- Active attack vector trend breakdown.
- Filterable and searchable audit history log with one-click full detail inspector and JSON export.

### 5. 🧩 Client Integration Simulator
- **Chrome Extension Simulator**: Demonstrates live, in-browser pre-click intervention and blocking before visiting malicious pages.
- **Mobile Guard Simulator**: Demonstrates real-time smartphone notification intercepting fraudulent SMS messages.

### 6. ⚡ Developer API Playground
- Interactive REST testing console with live request/response inspection and ready-to-copy **cURL** and **Python** code snippets.

def extract_url_features(url: str) -> list:
    """Extract numeric features from a URL for machine learning."""
    if not url.startswith(("http://", "https://")):
        url = "http://" + url
    
    parsed = urlparse(url)
    hostname = (parsed.hostname or "").lower()
    path = parsed.path.lower()
    full_url = url.lower()
    
    length = len(full_url)
    host_length = len(hostname)
    num_dots = hostname.count(".")
    num_hyphens = hostname.count("-")
    num_at = full_url.count("@")
    num_question = full_url.count("?")
    num_equal = full_url.count("=")
    num_slashes = full_url.count("/")
    
    # Check if host is raw IP address
    is_ip = 1.0 if re.match(r"^(\d{1,3}\.){3}\d{1,3}$", hostname) else 0.0
    
    # Entropy of hostname
    prob = [float(hostname.count(c)) / len(hostname) for c in set(hostname)] if hostname else [0]
    entropy = -sum(p * math.log(p, 2) for p in prob) if hostname else 0.0
    
    # Subdomain depth
    subdomains = hostname.split(".")
    tld = subdomains[-1] if len(subdomains) > 1 else ""
    is_suspicious_tld = 1.0 if tld in SUSPICIOUS_TLDS else 0.0
    subdomain_count = max(0, len(subdomains) - 2)
    
    # Brand impersonation in hostname or path
    brand_mentions = sum(1.0 for brand in POPULAR_BRANDS if brand in full_url)
    
    # Suspicious keywords
    keywords = ["login", "signin", "verify", "update", "bank", "account", "secure", "wallet", "free", "gift", "bonus", "claim"]
    keyword_count = sum(1.0 for kw in keywords if kw in full_url)
    
    is_https = 1.0 if parsed.scheme == "https" else 0.0
    
    return [
        length,
        host_length,
        num_dots,
        num_hyphens,
        num_at,
        num_question,
        num_equal,
        num_slashes,
        is_ip,
        entropy,
        is_suspicious_tld,
        subdomain_count,
        brand_mentions,
        keyword_count,
        is_https
    ]

        processed_url = cleaned_url

    path = parsed.path.lower()
    query = parsed.query.lower()
    full_str = processed_url.lower()
    
    reasons = []
    highlights = []
    signals = []
    rule_score_delta = 0
    
    # Check if host is in verified whitelist

        })
        signals.append("Raw IP address used in host")
        highlights.append(hostname)

    # 2. Suspicious TLD
    subdomains = hostname.split(".")
    tld = subdomains[-1] if len(subdomains) > 1 else ""
    if tld in SUSPICIOUS_TLDS:
        rule_score_delta += 30
        reasons.append({
            "factor": "High-Risk Domain Extension",
            "severity": "HIGH",
            "description": f"Uses '.{tld}' top-level domain, commonly associated with burner domains, malware distribution, and zero-day phishing campaigns."
        })
        signals.append(f"High-risk TLD (.{tld})")
        highlights.append(f".{tld}")

    # 3. Brand Impersonation / Typosquatting
    brand_impersonated = None
    for brand, legit_domains in POPULAR_BRANDS.items():
        if brand in full_str:
            is_legit = any(hostname == ld or hostname.endswith("." + ld) for ld in legit_domains)
            if not is_legit:
                brand_impersonated = brand
                rule_score_delta += 45
                reasons.append({
                    "factor": "Brand Impersonation / Spoofing",
                    "severity": "CRITICAL",
                    "description": f"Impersonates target brand '{brand.title()}' on an unverified domain ('{hostname}'). Highly indicative of credential harvesting."
                })
                signals.append(f"Impersonating {brand.title()}")
                highlights.append(brand)
                break

    # 4. Homoglyphs & Leetspeak (e.g. paypa1, micros0ft, amzon, goog1e)
    leetspeak_map = [
        (r"paypa[l1i]", "PayPal"),
        (r"micros[o0]ft", "Microsoft"),
        (r"arnazon|amaz0n", "Amazon"),
        (r"wellsfarg[o0]", "Wells Fargo"),
        (r"netfl[i1]x", "Netflix")
    ]
    for pattern, brand_name in leetspeak_map:
        if re.search(pattern, hostname) and not any(hostname.endswith(d) for d in [f"{brand_name.lower().replace(' ', '')}.com"]):
            rule_score_delta += 40
            reasons.append({
                "factor": "Typosquatting / Character Substitution",
                "severity": "CRITICAL",
                "description": f"Domain contains deceptive spelling designed to mimic '{brand_name}' using lookalike characters."
            })
            signals.append("Typosquatting detected")

    # 5. Excessive subdomains or deceptive subdomain chaining (e.g. paypal.com.verify-user.top)
    if len(subdomains) > 3:
        rule_score_delta += 20
        reasons.append({
            "factor": "Deceptive Subdomain Stacking",
            "severity": "MEDIUM",
            "description": f"Contains {len(subdomains)} domain segments. Attackers stack subdomains to trick mobile browser URL preview bars."
        })
        signals.append("Subdomain stacking")

    # 6. Sensitive keywords in path/query (login, signin, verify, kyc, secure)
    sensitive_keywords = ["login", "signin", "verify", "update", "bank", "account", "secure", "wallet", "apk", "billing", "kyc"]
    found_keywords = [kw for kw in sensitive_keywords if kw in full_str]
    if found_keywords:
        rule_score_delta += min(25, len(found_keywords) * 10)
        reasons.append({
            "factor": "Credential Harvesting Keywords",
            "severity": "HIGH" if brand_impersonated else "MEDIUM",
            "description": f"URL targets sensitive actions with keywords: {', '.join(found_keywords)}."
        })
        signals.append(f"Keywords: {', '.join(found_keywords[:3])}")
        highlights.extend(found_keywords)

    # 7. Unencrypted HTTP with sensitive actions
    if parsed.scheme == "http" and (brand_impersonated or found_keywords):
        rule_score_delta += 15
        reasons.append({
            "factor": "Insecure Protocol (HTTP)",
            "severity": "HIGH",
            "description": "Sensitive login/verification portal transmitted over unencrypted HTTP protocol."
        })
        signals.append("Plain HTTP protocol")

    # 8. ML Model inference
    ml_prob = 0.5
    if url_classifier is not None:
        try:
            feats = extract_url_features_vector(cleaned_url)
            ml_prob = float(url_classifier.predict_proba([feats])[0][1])
        except Exception as e:
            print(f"[Detector] ML predict error: {e}")

    # Combine ML probability (40%) + Rule score delta (60%)
    base_ml_score = ml_prob * 100
    final_score = int(min(99, max(5, (base_ml_score * 0.4) + (min(100, rule_score_delta) * 0.6))))
    
    # Floor / Ceiling enforcement based on clear rules
    if brand_impersonated and tld in SUSPICIOUS_TLDS:
        final_score = max(final_score, 88)
    elif is_ip and found_keywords:
        final_score = max(final_score, 92)

    # Classification tier
    if final_score >= 70:
        classification = "DANGEROUS"
    elif final_score >= 30:
        classification = "SUSPICIOUS"
    else:
        classification = "SAFE"

    # Threat radar factors (0 to 100 risk)
    factors = {
        "domain_trust": max(5, 100 - (rule_score_delta * 1.1)),
        "brand_integrity": 15 if brand_impersonated else (60 if found_keywords else 95),
        "structural_safety": max(10, 100 - (len(subdomains) * 18 + (30 if is_ip else 0))),
        "protocol_security": 20 if parsed.scheme == "http" else 90
    }

    # Actionable guidance
    if classification == "DANGEROUS":
        actions = [
            "DO NOT click this link or submit any passwords, card numbers, or OTPs.",
            "If you already entered information, immediately change your password on the official website.",
            "Report this malicious link to the national cybersecurity portal or anti-phishing workgroup."
        ]
        summary = f"High-confidence phishing hazard detected. This URL attempts to deceive users with impersonation and evasive hosting structures."
    elif classification == "SUSPICIOUS":
        actions = [
            "Exercise caution: Verify the domain name carefully before taking any action.",
            "Do not enter personal or payment credentials on this unverified page.",
            "Navigate directly to the organization's official website instead of using this link."
        ]
        summary = f"Suspicious characteristics observed. URL exhibits indicators commonly seen in unverified promotions or tracking redirects."
    else:
        actions = [
            "The URL appears structurally consistent with legitimate web destinations.",
            "Always verify you are on HTTPS before submitting private details."
        ]
        summary = "No anomalous phishing signatures or deceptive patterns were found for this URL."

    return {
        "input": cleaned_url,
        "type": "url",
        "risk_score": final_score,
        "classification": classification,
        "confidence": round(85.0 + (abs(final_score - 50) * 0.28), 1),
        "summary": summary,
        "reasons": reasons if reasons else [{"factor": "Baseline Security", "severity": "SAFE", "description": "Standard URL syntax with no malicious traits."}],
        "factors": factors,
        "highlights": list(set(highlights)),
        "actions": actions,
        "analyzed_at": datetime.utcnow().isoformat()
    }

URGENCY_REGEX = re.compile(
    r"\b(urgent|immediately|within \d+ (hours?|mins?|days?)|blocked|suspended|deactivated|terminated|expir(es?|ing) today|act now|last (call|warning|chance)|final notice|disconnect(ed)?|freeze|frozen)\b",
    re.IGNORECASE
)

FINANCIAL_REGEX = re.compile(
    r"\b(won|lottery|cash prize|bitcoin|crypto|free iphone|airdrop|\$\d+[\d,]*|₹\d+[\d,]*|grant of|refund of|earn \$\d+|congratulations winner|bonus deposit|guaranteed profit|exclusive gift)\b",
    re.IGNORECASE
)

COERCION_REGEX = re.compile(
    r"\b(arrest warrant|court summons|police complaint|legal action|investigation|penalty|fine of|fbi|tax department|customs officer|jail|law enforcement|enforcement directorate)\b",
    re.IGNORECASE
)

CREDENTIAL_REGEX = re.compile(
    r"\b(verify kyc|update pan|enter otp|share otp|confirm password|bank credentials|card details|cvv|social security|aadhaar|netbanking|secret pin|seed phrase|private key)\b",
    re.IGNORECASE
)

IMPERSONATION_REGEX = re.compile(
    r"\b(sbi|hdfc|icici|chase|wells fargo|bank of america|paypal|netflix|amazon customer|usps|dhl|fedex|electricity board|customer care|hr manager|telegram manager|support team)\b",
    re.IGNORECASE
)

CTA_REGEX = re.compile(
    r"\b(click here|click link|download apk|install file|call this number|call immediately|reply with|send gift card|contact on telegram)\b",
    re.IGNORECASE
)

def analyze_message(text: str) -> Dict[str, Any]:
    """Analyzes text/SMS/chat messages for social engineering, coercion & scam indicators."""
    cleaned = text.strip()
    reasons = []
    highlights = []
    rule_score_delta = 0
    signals = []

    # 1. Urgency / Panic induction
    urgency_matches = URGENCY_REGEX.findall(cleaned)
    if urgency_matches:
        # Extract matched words
        matched_words = [m[0] if isinstance(m, tuple) else m for m in urgency_matches]
        rule_score_delta += 28
        reasons.append({
            "factor": "Urgency & Artificial Panic",
            "severity": "HIGH",
            "description": f"Uses psychological pressure ({', '.join(set(matched_words[:3]))}) to force hurried action without critical thinking."
        })
        signals.append("High urgency tactics")
        highlights.extend(matched_words)

    # 2. Financial Bait / Unrealistic Rewards
    financial_matches = FINANCIAL_REGEX.findall(cleaned)
    if financial_matches:
        matched_words = [m[0] if isinstance(m, tuple) else m for m in financial_matches]
        rule_score_delta += 32
        reasons.append({
            "factor": "Financial / Lottery Bait",
            "severity": "HIGH",
            "description": f"Promises unrealistic rewards or sudden windfalls ({', '.join(set(matched_words[:3]))}) typical of advance-fee and task scams."
        })
        signals.append("Lottery/Reward bait")
        highlights.extend(matched_words)

    # 3. Legal Coercion & Intimidation
    coercion_matches = COERCION_REGEX.findall(cleaned)
    if coercion_matches:
        matched_words = [m[0] if isinstance(m, tuple) else m for m in coercion_matches]
        rule_score_delta += 45
        reasons.append({
            "factor": "Authoritarian Intimidation",
            "severity": "CRITICAL",
            "description": f"Employs legal/police threats ({', '.join(set(matched_words[:3]))}) to frighten recipients into compliance."
        })
        signals.append("Legal extortion threats")
        highlights.extend(matched_words)

    # 4. Credential / Sensitive Data Theft
    credential_matches = CREDENTIAL_REGEX.findall(cleaned)
    if credential_matches:
        matched_words = [m[0] if isinstance(m, tuple) else m for m in credential_matches]
        rule_score_delta += 40
        reasons.append({
            "factor": "Credential & Identity Harvesting",
            "severity": "CRITICAL",
            "description": f"Sollicits sensitive credentials ({', '.join(set(matched_words[:3]))}) which authorized institutions will NEVER request via casual messaging."
        })
        signals.append("Credential/OTP solicitation")
        highlights.extend(matched_words)

    # 5. Entity Impersonation
    impersonation_matches = IMPERSONATION_REGEX.findall(cleaned)
    if impersonation_matches:
        matched_words = [m[0] if isinstance(m, tuple) else m for m in impersonation_matches]
        rule_score_delta += 25
        reasons.append({
            "factor": "Brand / Authority Impersonation",
            "severity": "HIGH",
            "description": f"Poses as reputable entity ({', '.join(set(matched_words[:3]))}) to build unearned trust."
        })
        signals.append("Authority impersonation")
        highlights.extend(matched_words)

    # 6. Call to Action / Dangerous instruction
    cta_matches = CTA_REGEX.findall(cleaned)
    if cta_matches:
        matched_words = [m[0] if isinstance(m, tuple) else m for m in cta_matches]
        rule_score_delta += 20
        reasons.append({
            "factor": "Manipulative Call-To-Action",
            "severity": "MEDIUM",
            "description": f"Directs user to execute dangerous actions ({', '.join(set(matched_words[:2]))})."
        })
        signals.append("High-risk call to action")
        highlights.extend(matched_words)

    # 7. Check for embedded URLs in message
    url_pattern = r"(https?://[^\s]+|www\.[^\s]+|[a-zA-Z0-9-]+\.(?:xyz|top|buzz|sbs|cfd|club|link|online|rest)[^\s]*)"
    urls_found = re.findall(url_pattern, cleaned)
    embedded_url_result = None
    if urls_found:
        first_url = urls_found[0]
        embedded_url_result = analyze_url(first_url)
        if embedded_url_result["classification"] in ["DANGEROUS", "SUSPICIOUS"]:
            rule_score_delta += 35
            reasons.append({
                "factor": "Malicious Embedded Link",
                "severity": "CRITICAL",
                "description": f"Message contains link to '{first_url}' flagged as {embedded_url_result['classification']} (Risk: {embedded_url_result['risk_score']}/100)."
            })
            highlights.append(first_url)

    # ML Text Pipeline Inference
    ml_prob = 0.5
    if text_pipeline is not None:
        try:
            ml_prob = float(text_pipeline.predict_proba([cleaned])[0][1])
        except Exception as e:
            print(f"[Detector] NLP ML inference error: {e}")

    base_ml_score = ml_prob * 100
    final_score = int(min(99, max(4, (base_ml_score * 0.4) + (min(100, rule_score_delta) * 0.6))))

    # Coercion or credential theft with fake link should guarantee high risk
    if (coercion_matches or credential_matches) and (urls_found or urgency_matches):
        final_score = max(final_score, 85)

    if final_score >= 70:
        classification = "DANGEROUS"
    elif final_score >= 30:
        classification = "SUSPICIOUS"
    else:
        classification = "SAFE"

    # Social engineering factors for radar/bars
    factors = {
        "urgency_intensity": min(100, len(urgency_matches) * 45 + (20 if "immediately" in cleaned.lower() else 0)),
        "impersonation_index": min(100, len(impersonation_matches) * 50),
        "credential_theft_risk": min(100, len(credential_matches) * 55),
        "social_engineering": min(100, len(coercion_matches) * 50 + len(financial_matches) * 40)
    }

    if classification == "DANGEROUS":
        actions = [
            "DO NOT reply to this message, download any attachments/APKs, or click links.",
            "NEVER disclose OTPs, PINs, card numbers, or passwords over SMS or chat.",
            "Block the sender's phone number or account immediately.",
            "Verify independently via the official helpline or website of the named company."
        ]
        summary = "Dangerous scam message detected. Strong social-engineering tactics detected aimed at stealing credentials or money."
    elif classification == "SUSPICIOUS":
        actions = [
            "Be cautious: Unverified promotions or generic account warnings often conceal scams.",
            "Do not follow instructions in the message without independently checking your account.",
            "Look up the official contact details directly through a search engine or official app."
        ]
        summary = "Message displays suspicious patterns such as elevated urgency or promotional bait."
    else:
        actions = [
            "The message does not display obvious scam or coercion patterns.",
            "Always follow standard digital hygiene and never share one-time passcodes."
        ]
        summary = "No alarming social-engineering or phishing triggers were found in this text."

    return {
        "input": cleaned,
        "type": "message",
        "risk_score": final_score,
        "classification": classification,
        "confidence": round(84.0 + (abs(final_score - 50) * 0.29), 1),
        "summary": summary,
        "reasons": reasons if reasons else [{"factor": "Content Integrity", "severity": "SAFE", "description": "Message phrasing is typical of normal communication."}],
        "factors": factors,
        "highlights": list(set(highlights)),
        "embedded_url_analysis": embedded_url_result,
        "actions": actions,
        "analyzed_at": datetime.utcnow().isoformat()
    }

def analyze_email(sender: str, subject: str, body: str) -> Dict[str, Any]:
    """Analyzes email headers, subject urgency, spoofing signals, and body content."""
    reasons = []
    highlights = []
    rule_score_delta = 0
    signals = []

    # 1. Parse sender display name vs actual email address
    # E.g. "PayPal Security <noreply@secure-alert-service.xyz>"
    display_name = ""
    email_addr = sender.strip()
    match = re.match(r"^([^<]+)<([^>]+)>$", sender.strip())
    if match:
        display_name = match.group(1).strip()
        email_addr = match.group(2).strip()

    sender_domain = email_addr.split("@")[-1].lower() if "@" in email_addr else ""
    
    # Check display name spoofing
    for brand, legit_domains in POPULAR_BRANDS.items():
        if brand in display_name.lower() or brand in sender.lower():
            is_legit_domain = any(sender_domain == ld or sender_domain.endswith("." + ld) for ld in legit_domains)
            if not is_legit_domain:
                rule_score_delta += 48
                reasons.append({
                    "factor": "Sender Display Name Spoofing",
                    "severity": "CRITICAL",
                    "description": f"Display name poses as '{brand.title()}' but is dispatched from untrusted domain '@{sender_domain}'."
                })
                signals.append("Sender spoofing detected")
                highlights.append(display_name)
                highlights.append(sender_domain)
                break

    # Check free webmail pretending to be organization
    free_providers = ["gmail.com", "yahoo.com", "outlook.com", "hotmail.com", "aol.com"]
    if sender_domain in free_providers:
        org_keywords = ["support", "security", "billing", "service", "admin", "official", "helpdesk", "bank"]
        if any(k in display_name.lower() or k in email_addr.lower() for k in org_keywords):
            rule_score_delta += 35
            reasons.append({
                "factor": "Free Webmail Impersonation",
                "severity": "HIGH",
                "description": f"Official institution impersonated using a consumer free webmail provider (@{sender_domain})."
            })
            signals.append("Free webmail used for corporate persona")

    # 2. Subject Line Analysis
    subject_caps_ratio = sum(1 for c in subject if c.isupper()) / max(1, len(subject))
    if subject_caps_ratio > 0.4 and len(subject) > 10:
        rule_score_delta += 20
        reasons.append({
            "factor": "Excessive Subject Urgency / All-Caps",
            "severity": "MEDIUM",
            "description": "Subject line uses aggressive capital letters and urgent phrasing designed to spark panic."
        })
        signals.append("Urgent all-caps subject")

    # 3. Analyze Body using Message NLP Engine
    full_text_to_analyze = f"{subject}\n\n{body}"
    body_analysis = analyze_message(full_text_to_analyze)

    # Extract reasons from body
    for r in body_analysis["reasons"]:
        if r["factor"] != "Content Integrity":
            reasons.append(r)
    highlights.extend(body_analysis["highlights"])

    # Score fusion
    combined_score = int(min(99, max(5, (body_analysis["risk_score"] * 0.6) + (rule_score_delta * 0.5))))
    
    if any(r["severity"] == "CRITICAL" for r in reasons):
        combined_score = max(combined_score, 82)

    if combined_score >= 70:
        classification = "DANGEROUS"
    elif combined_score >= 30:
        classification = "SUSPICIOUS"
    else:
        classification = "SAFE"

    factors = {
        "sender_reputation": max(5, 100 - (rule_score_delta * 1.2)),
        "content_safety": max(5, 100 - body_analysis["risk_score"]),
        "social_engineering": body_analysis["factors"]["social_engineering"],
        "link_risk": body_analysis["embedded_url_analysis"]["risk_score"] if body_analysis["embedded_url_analysis"] else 10
    }

    if classification == "DANGEROUS":
        actions = [
            "Mark as Phishing / Spam in your email client immediately.",
            "DO NOT click any buttons or hyperlinks in the message.",
            "Do not open or preview any attachments.",
            "Contact your organization's IT security team or the reported company through their verified portal."
        ]
        summary = "Dangerous phishing email detected. Evidence of sender spoofing or malicious payload delivery."
    elif classification == "SUSPICIOUS":
        actions = [
            "Inspect the sender's full email address and SPF/DKIM headers.",
            "If in doubt, forward to your cybersecurity helpdesk.",
            "Do not click links; open a fresh browser tab and visit the service directly."
        ]
        summary = "Suspicious email signals detected. Sender identity or messaging triggers caution."
    else:
        actions = [
            "Email passes primary security criteria.",
            "Verify links before clicking as a baseline precaution."
        ]
        summary = "No anomalous spoofing or social engineering indicators found."

    return {
        "input": f"From: {sender}\nSubject: {subject}",
        "type": "email",
        "sender": sender,
        "subject": subject,
        "risk_score": combined_score,
        "classification": classification,
        "confidence": round(86.0 + (abs(combined_score - 50) * 0.27), 1),
        "summary": summary,
        "reasons": reasons if reasons else [{"factor": "Sender & Content Trust", "severity": "SAFE", "description": "Sender headers and email body exhibit valid, trustworthy characteristics."}],
        "factors": factors,
        "highlights": list(set(highlights)),
        "embedded_url_analysis": body_analysis.get("embedded_url_analysis"),
        "actions": actions,
        "analyzed_at": datetime.utcnow().isoformat()
    }

import React from 'react';

export default function RiskGauge({ score, classification, confidence }) {
  // Normalize score between 0 and 100
  const validScore = Math.max(0, Math.min(100, score || 0));
  
  // Circumference for r=54: 2 * PI * 54 = ~339.29
  const radius = 54;
  const circumference = 2 * Math.PI * radius;
  const strokeDashoffset = circumference - (validScore / 100) * circumference;

  let colorClass = 'text-emerald-500';
  let bgGlow = 'rgba(16, 185, 129, 0.2)';
  let badgeBg = 'bg-emerald-500/10 text-emerald-400 border-emerald-500/30';
  let badgeIcon = '✓';

  if (classification === 'DANGEROUS' || validScore >= 70) {
    colorClass = 'text-red-500';
    bgGlow = 'rgba(239, 68, 68, 0.25)';
    badgeBg = 'bg-red-500/10 text-red-400 border-red-500/30';
    badgeIcon = '⚠';
  } else if (classification === 'SUSPICIOUS' || validScore >= 30) {
    colorClass = 'text-amber-500';
    bgGlow = 'rgba(245, 158, 11, 0.25)';
    badgeBg = 'bg-amber-500/10 text-amber-400 border-amber-500/30';
    badgeIcon = '⚡';
  }

  return (
    <div className="flex flex-col items-center justify-center p-6 bg-slate-900/60 rounded-2xl border border-slate-800 relative overflow-hidden">
      {/* Background ambient radial glow */}
      <div 
        className="absolute w-40 h-40 rounded-full blur-3xl pointer-events-none transition-all duration-700"
        style={{ backgroundColor: bgGlow }}
      />

      <div className="relative w-36 h-36 flex items-center justify-center">
        <svg className="w-full h-full transform -rotate-90" viewBox="0 0 130 130">
          {/* Track background */}
          <circle
            cx="65"
            cy="65"
            r={radius}
            stroke="currentColor"
            strokeWidth="10"
            fill="transparent"
            className="text-slate-800"
          />
          {/* Animated score ring */}
          <circle
            cx="65"
            cy="65"
            r={radius}
            stroke="currentColor"
            strokeWidth="10"
            fill="transparent"
            strokeDasharray={circumference}
            strokeDashoffset={strokeDashoffset}
            strokeLinecap="round"
            className={`${colorClass} transition-all duration-1000 ease-out`}
          />
        </svg>

        <div className="absolute inset-0 flex flex-col items-center justify-center text-center">
          <span className="text-4xl font-extrabold tracking-tight text-white font-mono">
            {validScore}
          </span>
          <span className="text-xs uppercase tracking-widest text-slate-400 font-medium">
            / 100 Risk

      </div>

  const [duration, setDuration] = useState(null);

  const endpointConfig = {
    url: {
      method: 'POST',
      path: '/api/scan/url',
      defaultBody: { url: "http://paypal-security-verification-alert.xyz/login.php" }
    },
    message: {
      method: 'POST',
      path: '/api/scan/message',
      defaultBody: { message: "URGENT: Your bank account will be blocked within 24 hours. Update KYC now at http://sbi-kyc.xyz" }
    },
    email: {
      method: 'POST',
      path: '/api/scan/email',
      defaultBody: {
        sender: "Netflix Support <billing@movie-renew-now.top>",
        subject: "Action Required: Payment Declined",
        body: "Your account is on hold. Renew billing details at http://netflix-renew.buzz"
      }
    },
    stats: {
      method: 'GET',
      path: '/api/stats',
      defaultBody: null
    }
  };

  const handleSelectEndpoint = (key) => {
    setSelectedEndpoint(key);
    const cfg = endpointConfig[key];
    setRequestBody(cfg.defaultBody ? JSON.stringify(cfg.defaultBody, null, 2) : '');
    setResponseOutput(null);
    setDuration(null);
  };

  const handleExecute = async () => {
    setLoading(true);
    setDuration(null);
    const startTime = performance.now();
    try {
      const cfg = endpointConfig[selectedEndpoint];
      let res;
      if (cfg.method === 'POST') {
        const parsed = JSON.parse(requestBody);
        res = await fetch(cfg.path, {
          method: 'POST',
          headers: { 'Content-Type': 'application/json' },
          body: JSON.stringify(parsed)
        });
      } else {
        res = await fetch(cfg.path);
      }
      const data = await res.json();
      const endTime = performance.now();
      setDuration(Math.round(endTime - startTime));
      setResponseOutput(data);
    } catch (err) {
      setResponseOutput({ error: err.message || 'API request failed' });
    } finally {
      setLoading(false);
    }
  };

res = requests.get("http://localhost:8000/api/stats")
print(res.json())`

payload = ${requestBody}
res = requests.post("http://localhost:8000${endpointConfig[selectedEndpoint].path}", json=payload)
print(res.json())`;

      <div>
        <h2 className="text-2xl font-bold text-white tracking-tight flex items-center gap-2.5">
          <Terminal className="w-6 h-6 text-cyan-400" />
          <span>Interactive REST API Playground & Integration Hub</span>
        </h2>
        <p className="text-xs text-slate-400 mt-1">

            key={key}
            onClick={() => handleSelectEndpoint(key)}
            className={`px-4 py-2 rounded-xl text-xs font-mono font-semibold transition border flex items-center gap-2 ${

import React, { useState } from 'react';
import { Flag, X, CheckCircle2 } from 'lucide-react';

export default function ReportModal({ targetItem, onClose }) {
  const [threatType, setThreatType] = useState('Phishing Link');
  const [notes, setNotes] = useState('');
  const [submitted, setSubmitted] = useState(false);
  const [loading, setLoading] = useState(false);

  const handleSubmit = async (e) => {
    e.preventDefault();
    setLoading(true);
    try {
      await fetch('/api/report', {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({
          threat_type: threatType,
          target_content: targetItem?.input || 'N/A',
          notes: notes
        })
      });
      setSubmitted(true);
      setTimeout(() => {
        onClose();
      }, 1800);
    } catch (e) {
      setSubmitted(true);
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center p-4 bg-black/70 backdrop-blur-sm animate-in fade-in duration-200">
      <div className="w-full max-w-md bg-slate-900 border border-slate-800 rounded-3xl p-6 shadow-2xl relative">
        <button
          onClick={onClose}
          className="absolute right-4 top-4 text-slate-400 hover:text-white p-1 rounded-lg hover:bg-slate-800 transition"
        >
          <X className="w-5 h-5" />
        </button>

        {submitted ? (
          <div className="text-center py-6">
            <CheckCircle2 className="w-12 h-12 text-emerald-400 mx-auto mb-3" />
            <h3 className="text-lg font-bold text-white">Report Submitted!</h3>
            <p className="text-xs text-slate-400 mt-1">
              Thank you for contributing to the community threat defense network.
            </p>
          </div>
        ) : (
          <form onSubmit={handleSubmit} className="space-y-4">
            <div className="flex items-center gap-2 text-rose-400 text-sm font-semibold">
              <Flag className="w-4 h-4" />
              <span>Report Malicious Threat / Scam</span>
            </div>

            <div>
              <label className="block text-xs text-slate-400 mb-1">Target Content:</label>
              <div className="p-2.5 rounded-xl bg-slate-950 border border-slate-800 text-xs text-slate-300 font-mono break-all max-h-20 overflow-y-auto">
                {targetItem?.input || 'Selected Scan Item'}
              </div>
            </div>

            <div>
              <label className="block text-xs text-slate-400 mb-1">Report Category:</label>
              <select
                value={threatType}
                onChange={(e) => setThreatType(e.target.value)}
                className="w-full bg-slate-950 border border-slate-800 rounded-xl px-3 py-2 text-xs text-slate-200 focus:outline-none focus:border-cyan-500"
              >
                <option value="Phishing Link">Phishing Link / Lookalike Domain</option>
                <option value="SMS Scam">SMS / Chat Smishing</option>
                <option value="Email Spoofing">Email Spoofing / BEC</option>
                <option value="False Positive">False Positive (Item is Safe)</option>
              </select>
            </div>

            <div>
              <label className="block text-xs text-slate-400 mb-1">Additional Context (Optional):</label>
              <textarea
                rows={3}
                value={notes}
                onChange={(e) => setNotes(e.target.value)}
                placeholder="Where did you receive this link? Any details regarding impersonation..."
                className="w-full bg-slate-950 border border-slate-800 rounded-xl p-2.5 text-xs text-slate-200 focus:outline-none focus:border-cyan-500 resize-none"
              />
            </div>

            <div className="flex items-center justify-end gap-2 pt-2">
              <button
                type="button"
                onClick={onClose}
                className="px-4 py-2 rounded-xl bg-slate-800 text-slate-300 text-xs hover:bg-slate-700 transition"
              >
                Cancel
              </button>
              <button
                type="submit"
                disabled={loading}
                className="px-5 py-2 rounded-xl bg-rose-600 hover:bg-rose-500 text-white text-xs font-semibold transition flex items-center gap-1.5"
              >
                {loading ? 'Submitting...' : 'Submit Threat Report'}
              </button>
            </div>
          </form>
        )}
      </div>
    </div>
  );
}
